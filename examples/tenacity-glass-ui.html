✨ Tenacity Glass UI

灵感来自 Minecraft Tenacity Client，采用渐变背景 + 白色毛玻璃设计

🎨 设计风格

Tenacity Glass UI 采用浅色系渐变背景（浅蓝 → 浅紫 → 浅粉）， 配合 75% 透明度的白色毛玻璃效果，营造出轻盈、现代、优雅的视觉体验。

浅蓝渐变 毛玻璃效果 75% 透明度 圆角设计 悬停动画 响应式布局

✨ 核心特性

🎨

渐变背景

浅蓝到粉色的多层次渐变，柔和而富有层次感

💎

毛玻璃效果

backdrop-filter 实现的真实毛玻璃模糊效果

🚀

流畅动画

所有交互都有平滑的过渡动画和悬停效果

📱

响应式设计

完美适配桌面、平板和移动设备

🎯

圆角设计

大圆角（24px）和圆形按钮（999px）

✨

渐变元素

按钮、标题、图标都使用渐变配色

📝 代码示例

以下是实现毛玻璃卡片的核心 CSS 代码：

/* 毛玻璃卡片 */ .glass-card { background: rgba(255, 255, 255, 0.75); backdrop-filter: blur(20px); -webkit-backdrop-filter: blur(20px); border: 1px solid rgba(255, 255, 255, 0.9); border-radius: 24px; box-shadow: 0 8px 32px rgba(31, 38, 135, 0.15); transition: all 0.4s cubic-bezier(0.4, 0, 0.2, 1); } .glass-card:hover { transform: translateY(-4px); box-shadow: 0 12px 48px rgba(31, 38, 135, 0.25); background: rgba(255, 255, 255, 0.85); }

渐变背景实现：

body { background: linear-gradient(135deg, #e0f2fe 0%, /* 浅蓝 */ #dbeafe 15%, #e0e7ff 30%, /* 浅紫 */ #ede9fe 45%, #fce7f3 60%, /* 浅粉 */ #fecdd3 75%, #fecaca 90%, #fee2e2 100% ); background-attachment: fixed; }

⚡ starry:// 协议详解

OpenStarry Code 私有协议，用于快速配置 API、安装 Skills 和加载扩展。

📡 API 配置导入

支持所有主流 LLM 提供商的快速配置

# ========== 商业 API 提供商 ========== # 1. OpenRouter（推荐 - 支持多个模型） starry://api/import?provider=openrouter&key=env:OPENROUTER_API_KEY # 2. Anthropic Claude（最新 Sonnet 4.5） starry://api/import?provider=anthropic&model=claude-sonnet-4-5&key=env:ANTHROPIC_API_KEY # 3. OpenAI GPT-4 starry://api/import?provider=openai&model=gpt-4o&key=env:OPENAI_API_KEY # 4. Google Gemini starry://api/import?provider=gemini&model=gemini-2.0-flash&key=env:GEMINI_API_KEY # 5. Azure OpenAI（需要指定 base_url） starry://api/import?provider=azure&model=gpt-4&key=env:AZURE_API_KEY&base_url=https://your-resource.openai.azure.com # 6. 智谱 AI (GLM-4) starry://api/import?provider=zhipu&model=glm-4-plus&key=env:ZHIPU_API_KEY # 7. DeepSeek starry://api/import?provider=deepseek&model=deepseek-chat&key=env:DEEPSEEK_API_KEY # 8. Moonshot AI (Kimi) starry://api/import?provider=moonshot&model=moonshot-v1-32k&key=env:MOONSHOT_API_KEY # ========== 本地/开源模型 ========== # 9. Ollama 本地运行（无需 API key） starry://api/import?provider=ollama&model=llama3.1 # 10. Ollama 指定端口 starry://api/import?provider=ollama&model=qwen2.5&base_url=http://localhost:11434 # ========== 从配置文件导入 ========== # 11. 从远程 JSON 导入 starry://api/import?url=https://example.com/openai-config.json&type=openai # 12. 从本地 TOML 文件导入 starry://api/import?url=file:///C:/configs/anthropic.toml&type=anthropic # 13. 从本地 JSON 文件导入 starry://api/import?url=file:///home/user/configs/openrouter.json&type=openrouter

📦 配置文件格式示例

JSON 格式（openai-config.json）：

{ "version": "1.0", "provider": "openai", "config": { "api_key_env": "OPENAI_API_KEY", "base_url": "https://api.openai.com/v1", "model": "gpt-4o", "timeout": 60, "max_retries": 3 }, "router": { "mode": "recommended", "tiers": { "quick": "gpt-4o-mini", "normal": "gpt-4o", "advanced": "gpt-4-turbo" } } }

TOML 格式（anthropic.toml）：

[llm] provider = "anthropic" model = "claude-sonnet-4-5" api_key_env = "ANTHROPIC_API_KEY" base_url = "https://api.anthropic.com" timeout = 120 [router] mode = "recommended" [router.tier_models] quick = "claude-3-haiku" normal = "claude-3.5-sonnet" advanced = "claude-3-opus"

🔧 Skill 安装

# 从 GitHub 安装（默认 main 分支） starry://skill/install?github=openstarry/deep-research # 指定分支或标签 starry://skill/install?github=openstarry/awesome-skill&ref=v1.2.0 # 指定仓库子路径 starry://skill/install?github=myorg/skills&ref=main&subpath=pdf-tools # 从 ClawHub 安装 starry://skill/install?clawhub=deep-research-pro # 从本地路径安装 starry://skill/install?local=file:///path/to/my-skill

🔌 扩展加载

# 加载 Python 扩展 starry://extension/load?path=file:///plugins/my_extension.py&type=python # 加载 Java 扩展 starry://extension/load?path=file:///C:/plugins/code-analyzer.jar&type=java # 加载 Go 扩展（Linux/macOS） starry://extension/load?path=file:///usr/local/lib/analyzer.so&type=go # 从 URL 加载扩展 starry://extension/load?path=https://example.com/extensions/analyzer.so&type=go

📋 批量配置

创建 setup.txt 文件，每行一个协议 URL：

# setup.txt - 一键配置完整环境 starry://api/import?provider=openrouter&key=env:OPENROUTER_API_KEY starry://api/import?provider=ollama&model=llama3.1 starry://skill/install?github=openstarry/deep-research starry://skill/install?clawhub=pdf-tools

执行批量配置：

# 批量处理所有配置 openstarry-code protocol batch setup.txt # JSON 输出格式 openstarry-code protocol batch setup.txt --json

🎯 高级配置示例

自定义超时、重试、代理等高级参数：

# 自定义超时和重试 starry://api/import?provider=openai&model=gpt-4o&key=env:OPENAI_API_KEY&timeout=120&max_retries=5 # 使用代理 starry://api/import?provider=anthropic&key=env:ANTHROPIC_API_KEY&proxy=http://proxy.example.com:8080 # 设置自定义 base_url（私有部署） starry://api/import?provider=openai&key=env:CUSTOM_API_KEY&base_url=https://my-api.example.com/v1 # 配置模型路由（多层级） starry://api/import?url=https://example.com/router-config.json&type=openai # 多 provider 组合配置 starry://api/import?provider=openrouter&key=env:OPENROUTER_API_KEY starry://api/import?provider=ollama&model=qwen2.5 starry://api/import?provider=anthropic&model=claude-sonnet-4-5&key=env:ANTHROPIC_API_KEY
