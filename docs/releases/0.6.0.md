# OpenStarry Code 0.6.0

Release date: 2026-08-29

OpenStarry Code 0.6.0 adds read-only remote file browsing (SSH, FTP, WSL, MCP,
and cloned Git repositories) to the IDE panel, real-time AI command mirroring
in the terminal, a computer-use module with a visual cursor overlay, session
handoff and recovery, and per-line green/red change marks in the code
interpreter.

## Highlights

- The IDE panel now browses remote file systems over SSH, FTP, WSL, MCP, and
  locally cloned Git repositories. The Git transport scans the workspace for
  cloned repositories and exposes their trees and file contents read-only,
  with path-traversal protection.
- The terminal panel can mirror the PowerShell commands the agent executes,
  streaming them in real time together with their output, without changing
  how commands run.
- The computer-use module ships with a visual cursor overlay (4× supersampling,
  anti-aliased corners, and a glowing rectangular frame driven by a true
  distance field), a desktop control session, and an MCP server surface.
- Per-line green (added) and red (modified) change marks render in the
  right-hand code interpreter for local project files, computed against an
  in-memory project snapshot of the workspace.
- Session handoff and recovery, thinking mode, a workflow learner, a prompt
  compressor, and QA verification stages improve long-running and multi-turn
  work.
- Durable Goals and the bundled `application-build` workflow remain available
  for long-running project work across reconnects, and the migration layer
  continues importing legacy data on upgrade.
- New settings panels for SSH, FTP, and MCP servers, a Computer Use preview
  modal, and the Tenacity theme.
- Fixed the Web UI showing an empty chat on cold start by redirecting to a new
  chat.

## Verification

- Backend gateway and remote route suites, including the new Git/FTP/SSH
  browsing and path-traversal tests, pass.
- IDE change-mark suite passes, including the snapshot baseline and large-file
  classification boundary cases.
- Web UI builds pass `vue-tsc`, the architecture guard, and i18n checks; the

- No configured API key is embedded in source or release notes.

The GitHub release workflow builds the versioned Python artifacts, macOS
Electron assets, Windows NSIS/MSI installers, updater metadata, and checksums
from tag `v0.6.0`.

Windows installers are currently unsigned. Verify downloaded files against
`SHA256SUMS` before deployment.

Back up the active profile before upgrading. Install over the existing desktop
application; the migration layer imports legacy data and leaves the source profile available
for rollback. Use either MSI or NSIS consistently on a given machine rather
than installing both formats to separate destinations.

## Privacy

Disable non-user-initiated network observability with:

```sh
OPENSTARRY_CODE_PRIVACY_DISABLE_NETWORK_OBSERVABILITY=true
```

or:

```toml
[privacy]
disable_network_observability = true
```

The legacy `OPENSTARRY_CODE_TELEMETRY_DISABLED=true` and
`OPENSTARRY_CODE_UPDATE_CHECK_DISABLED=true` controls remain supported.
