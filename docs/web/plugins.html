⚙️

原生扩展

Python/Java/Go 编写的原生代码模块，提供核心能力扩展

✓ 高性能

✓ 系统集成

六层优先级架构

Skills 遵循六层加载优先级，从低到高：

1

Extra 层

配置文件指定的额外目录

~/.openstarry-code/extra-skills/
2

Bundled 层

随 OpenStarry Code 发布的内置 Skills

src/openstarry_code/skills/bundled/
3

Managed 层

本地安装目录（推荐安装位置）

~/.openstarry-code/skills/
4

Personal 层

用户个人目录

~/.agents/skills/
5

Project 层

项目级目录

{workspace}/.agents/skills/
6

Workspace 层（最高优先级）

工作区目录

{workspace}/skills/
💡
优先级规则
高层级的 Skill 会覆盖低层级的同名 Skill，实现灵活的定制化

安装插件

使用 starry:// 协议一键安装（类似 VS Code 的 vscode:extension/...）：

# 从 GitHub 安装
starry://skill/install?github=yourname/awesome-skill

# 指定版本
starry://skill/install?github=yourname/awesome-skill&ref=v1.0.0

# 从子目录安装
starry://skill/install?github=org/monorepo&subpath=skills/my-skill

使用 CLI 命令安装：

# GitHub 源
openstarry-code skills install yourname/awesome-skill --source github

# ClawHub 源
openstarry-code skills install skill-id --source clawhub

# 本地路径
openstarry-code skills install /path/to/skill --source local

创建 plugins.txt 批量安装：

# OpenStarry Code 插件配置
starry://skill/install?github=community/code-review
starry://skill/install?github=community/test-generator
starry://skill/install?github=myteam/custom-tool&ref=v2.0.0
starry://extension/load?path=https://cdn.example.com/analyzer.so&type=go

执行批量安装：

openstarry-code protocol batch plugins.txt

Skill 插件

什么是 Skill？

Skill 是包含 AI 指令的轻量级插件，使用 Markdown 编写，YAML 元数据定义：

Markdown 
---
name: code-reviewer
description: "Review code for quality and best practices"
triggers:
  - "review code"
  - "code review"
provenance:
  origin: community
  license: MIT
metadata:
  risk: low
  capabilities:
    - filesystem-read
---

# Code Reviewer Skill

## Purpose
Review code for quality, security, and best practices.

## Instructions
1. Read the specified code files
2. Analyze code quality and patterns
3. Identify potential issues
4. Provide actionable suggestions

...

Skill 结构

my-skill/
├── SKILL.md          # 必需：Skill 定义文件
├── README.md         # 推荐：使用说明
├── LICENSE           # 推荐：开源许可证
├── scripts/          # 可选：辅助脚本
│   └── helper.py
└── resources/        # 可选：资源文件
    └── templates/

Python 扩展

最推荐的扩展开发语言，与 OpenStarry Code 核心无缝集成：

Python 
class MyExtension:
    def __init__(self):
        self.name = "my-extension"
        self.version = "1.0.0"
    
    def initialize(self, config):
        """初始化扩展"""
        return True
    
    def execute(self, command, args):
        """执行命令"""
        if command == "analyze":
            return self.analyze(args)
        return {"error": "Unknown command"}
    
    def cleanup(self):
        """清理资源"""
        pass

def get_extension():
    return MyExtension()
📦
安装 Python 扩展
starry://extension/load?path=https://example.com/ext.py&type=python
