认证方式

Gateway HTTP API 使用 WebSocket 连接和 Token 认证：

Python 
import os
from openstarry_code.gateway.client import GatewayClient

# 连接到 Gateway
client = GatewayClient(
    url="ws://localhost:18791/ws",
    token=os.environ.get("OPENSTARRY_TOKEN")
)

# 调用 API
result = await client.call("providers.list")

Provider API

列出所有 Provider

from openstarry_code.config import load_config

config = load_config()
providers = config.llm_providers

for provider in providers:
    print(f"{provider.provider_id}: {provider.provider_type}/{provider.model}")
# 列出所有 providers
openstarry-code providers list

# JSON 格式输出
openstarry-code providers list --json
// WebSocket RPC 调用
{
  "method": "providers.list",
  "params": {},
  "id": 1
}

添加 Provider

from openstarry_code.config import load_config
from openstarry_code.config.mutations import upsert_llm_provider

config = load_config()

# 添加 OpenRouter provider
upsert_llm_provider(config, {
    "provider_id": "my-openrouter",
    "provider_type": "openrouter",
    "model": "anthropic/claude-3.5-sonnet",
    "api_key_env": "OPENROUTER_API_KEY"
})

# 保存配置
config.save()
# 添加 provider
openstarry-code providers add \
  --id my-openrouter \
  --type openrouter \
  --model anthropic/claude-3.5-sonnet \
  --api-key-env OPENROUTER_API_KEY
# 使用 starry:// 协议快速添加
openstarry-code protocol handle \
  "starry://api/import?provider=openrouter&model=anthropic/claude-3.5-sonnet&key=env:OPENROUTER_API_KEY"
💡
支持的 Provider 类型
openrouter, anthropic, openai, gemini, azure, ollama, zhipu, qwen, baidu

配置参数

参数 类型 必需 说明
provider_id string ✅ Provider 唯一标识符
provider_type string ✅ Provider 类型
model string ✅ 模型名称
api_key_env string ❌ API Key 环境变量名
base_url string ❌ 自定义 API 端点
timeout integer ❌ 请求超时（秒）
max_retries integer ❌ 最大重试次数

Skills API

列出已安装的 Skills

from openstarry_code.skills import SkillRegistry

registry = SkillRegistry()
skills = registry.list_skills()

for skill in skills:
    print(f"{skill.name} - {skill.description}")
# 列出所有 skills
openstarry-code skills list

# 显示详细信息
openstarry-code skills list --verbose

# JSON 格式
openstarry-code skills list --json

安装 Skill

# 从 GitHub 安装
openstarry-code skills install yourname/awesome-skill --source github

# 从本地路径安装
openstarry-code skills install /path/to/skill --source local

# 指定版本
openstarry-code skills install yourname/awesome-skill --ref v1.0.0
# 使用 starry:// 协议安装
openstarry-code protocol handle \
  "starry://skill/install?github=yourname/awesome-skill"

# 指定版本和子路径
openstarry-code protocol handle \
  "starry://skill/install?github=org/repo&ref=v1.0.0&subpath=skills/my-skill"

查看 Skill 详情

Bash 
# 查看 skill 内容
openstarry-code skills view skill-name

# 检查 skill 健康状态
openstarry-code skills doctor skill-name

# 输出诊断信息为 JSON
openstarry-code skills doctor skill-name --json

Protocol API

starry:// 协议格式

starry:// 是 OpenStarry Code 的私有协议，用于快速配置和安装：

starry:///?

示例：
starry://api/import?provider=openrouter&key=env:API_KEY
starry://skill/install?github=user/repo&ref=v1.0.0
starry://extension/load?path=https://example.com/ext.so&type=go

处理协议 URL

# 处理单个 URL
openstarry-code protocol handle "starry://api/import?provider=ollama"

# 批量处理
openstarry-code protocol batch setup.txt

# 验证 URL（不执行）
openstarry-code protocol validate "starry://skill/install?github=user/repo"

# JSON 输出
openstarry-code protocol handle "starry://..." --json
from openstarry_code.protocol import StarryProtocolHandler

handler = StarryProtocolHandler()

# 处理单个 URL
result = await handler.handle("starry://api/import?provider=ollama")

# 批量处理
urls = [
    "starry://api/import?provider=openrouter&key=env:KEY",
    "starry://skill/install?github=user/repo"
]
results = await handler.handle_batch(urls)

# 检查结果
for result in results:
    if result.status == "success":
        print(f"✓ {result.message}")
    else:
        print(f"✗ {result.error}")

支持的协议操作

操作 格式 说明
api/import starry://api/import?provider=...&key=... 导入 API 配置
skill/install starry://skill/install?github=... 安装 Skill
extension/load starry://extension/load?path=...&type=... 加载扩展

Gateway API

WebSocket 连接

Gateway 通过 WebSocket 提供实时 RPC 接口：

JavaScript 
const ws = new WebSocket('ws://localhost:18791/ws');

// 发送 RPC 请求
ws.send(JSON.stringify({
  method: 'providers.list',
  params: {},
  id: 1
}));

// 接收响应
ws.onmessage = (event) => {
  const response = JSON.parse(event.data);
  console.log(response.result);
};

可用的 RPC 方法

方法 参数 返回
providers.list {} Provider 列表
providers.add {provider_id, provider_type, model, ...} 添加结果
skills.list {} Skill 列表
skills.install {source, ref?, subpath?} 安装结果
chat.create {provider_id, messages} 对话响应
