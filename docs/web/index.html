OpenStarry Code 文档

支持多 LLM 提供商的开源 AI Agent 运行时

快速开始

安装 OpenStarry Code

选择适合你的安装方式：

Bash 
# 使用 pipx 安装（推荐）
pipx install openstarry-code

# 使用 pip 安装
pip install openstarry-code

# 从源码安装
bash scripts/install_source.sh

启动 Gateway 服务

OpenStarry Code 通过 Gateway 提供 Web UI 和 API 服务：

Bash 
# 启动 Gateway（默认端口 18791）
openstarry-code gateway run

# 指定端口
openstarry-code gateway run --port 8080

# 后台运行
openstarry-code gateway start
ℹ️
访问 Web UI
Gateway 启动后，在浏览器中打开 http://localhost:18791

安装指南

系统要求

  • Python 3.10 或更高版本
  • Windows / macOS / Linux
  • 8GB RAM（推荐 16GB）
  • 互联网连接（用于访问 LLM 服务）

详细安装步骤

1

安装 Python

确保已安装 Python 3.10+：

python --version
2

安装 OpenStarry Code

使用 pipx 进行隔离安装（推荐）：

pipx install openstarry-code
3

验证安装

openstarry-code --version
openstarry-code --help
4

配置 LLM Provider

使用 starry:// 协议快速配置：

# 配置 OpenRouter
starry://api/import?provider=openrouter&key=env:OPENROUTER_API_KEY

# 配置 Ollama（本地）
starry://api/import?provider=ollama&model=llama3.1

基础配置

配置文件位置

OpenStarry Code 使用 TOML 格式的配置文件：

  • Windows: %APPDATA%\openstarry-code\config.toml
  • macOS: ~/Library/Application Support/openstarry-code/config.toml
  • Linux: ~/.config/openstarry-code/config.toml

配置 Provider

添加 LLM Provider 配置：

TOML 
[[llm_providers]]
provider_id = "my-openrouter"
provider_type = "openrouter"
model = "anthropic/claude-3.5-sonnet"
api_key_env = "OPENROUTER_API_KEY"

[[llm_providers]]
provider_id = "local-ollama"
provider_type = "ollama"
model = "llama3.1"
base_url = "http://localhost:11434"

使用 starry:// 协议配置

更快捷的配置方式：

# 使用 CLI 命令
openstarry-code protocol handle "starry://api/import?provider=openrouter&key=env:OPENROUTER_API_KEY"
# 在浏览器中打开
starry://api/import?provider=openrouter&key=env:OPENROUTER_API_KEY

# 或点击网页链接
一键配置
# 从配置文件导入
starry://api/import?url=https://example.com/config.json&type=openrouter
