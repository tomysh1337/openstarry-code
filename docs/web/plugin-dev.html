开发 Skill 插件

Skill 基本结构

每个 Skill 是一个包含 SKILL.md 文件的目录：

my-awesome-skill/
├── SKILL.md          # 必需：Skill 定义文件
├── README.md         # 可选：使用说明
├── scripts/          # 可选：辅助脚本
│   └── helper.py
└── resources/        # 可选：资源文件
    └── templates/

SKILL.md 格式

Skill 定义文件使用 YAML 前置元数据 + Markdown 正文的格式：

---
name: my-awesome-skill
description: "A clear one-sentence description"
description_zh: "该技能功能的中文描述"
triggers:
  - "keyword or phrase that activates this skill"
  - "another trigger phrase"
homepage: https://github.com/yourname/my-awesome-skill
provenance:
  origin: community
  license: MIT
  upstream_url: https://github.com/yourname/my-awesome-skill
  maintained_by: Your Name
requires:
  - python>=3.10
  - pip:pandas
metadata:
  risk: low
  capabilities:
    - filesystem-read
---

# My Awesome Skill

## Purpose

Explain what this skill does and when to use it.

## Instructions

Detailed instructions for the AI agent on how to use this skill.

### Step 1: Understand the Request

Guidelines for interpreting user input...

### Step 2: Execute the Task

Specific implementation steps...

### Step 3: Deliver the Result

How to format and present the output...

## Examples

### Example 1: Basic Usage

User request: "Do something awesome"

Expected behavior:
1. Analyze the request
2. Execute the task
3. Return the result

## Constraints

- Do not perform action X
- Always validate input Y
- Respect user preferences for Z
---
name: research-report-workflow
kind: meta
description: "Automated research report generation"
triggers:
  - "research report"
  - "academic paper"
meta_priority: 50
provenance:
  origin: bundled
  license: MIT
metadata:
  risk: medium
  capabilities:
    - filesystem-write
    - network-read
    - artifact-write
composition:
  inputs:
    topic:
      type: string
      required: true
    depth:
      type: integer
      default: 3
  steps:
    - id: gather
      skill: web-research
      inputs:
        query: "{{inputs.topic}}"
        max_results: 20
    - id: synthesize
      skill: content-synthesis
      inputs:
        sources: "{{steps.gather.output}}"
    - id: format
      skill: markdown-formatter
      inputs:
        content: "{{steps.synthesize.output}}"
  outputs:
    report: "{{steps.format.output}}"
---

# Research Report Workflow

Multi-step research and report generation workflow.

YAML 前置元数据字段

字段 类型 说明
name string 必需。Skill 唯一标识符（小写字母、数字、连字符）
description string 必需。简短的英文描述（一句话）
description_zh string 可选。中文描述
triggers list 触发该 Skill 的关键词或短语列表
kind string normal（默认）或 meta（Meta-Skill）
homepage string Skill 的主页 URL
provenance object 来源信息（origin, license, upstream_url, maintained_by）
requires list 依赖项列表（格式：python>=3.10、pip:package）
metadata object 元数据（risk 级别、capabilities 列表）
composition object 仅 Meta-Skill。定义工作流的输入、步骤和输出

Python 扩展开发

1. 创建扩展目录：

my-extension/
├── __init__.py       # 扩展入口
├── manifest.json     # 扩展元数据
├── handlers.py       # 功能实现
└── requirements.txt  # Python 依赖

2. manifest.json：

{
  "name": "my-extension",
  "version": "1.0.0",
  "description": "My awesome extension",
  "author": "Your Name",
  "license": "MIT",
  "entry_point": "__init__.py",
  "api_version": "1.0",
  "capabilities": [
    "tool-registry",
    "event-hooks",
    "config-provider"
  ],
  "permissions": [
    "filesystem-read",
    "network-request"
  ]
}

3. __init__.py：

from openstarry_code.extension import Extension
from openstarry_code.tools import Tool, ToolParameter

class MyExtension(Extension):
    def __init__(self):
        super().__init__(
            name="my-extension",
            version="1.0.0",
            description="My awesome extension"
        )
    
    def on_load(self):
        """扩展加载时调用"""
        self.register_tool(MyCustomTool())
        self.logger.info("Extension loaded")
    
    def on_unload(self):
        """扩展卸载时调用"""
        self.logger.info("Extension unloaded")

class MyCustomTool(Tool):
    def __init__(self):
        super().__init__(
            name="my_custom_tool",
            description="Does something awesome",
            parameters=[
                ToolParameter(
                    name="input_text",
                    type="string",
                    description="Input text to process",
                    required=True
                )
            ]
        )
    
    def execute(self, input_text: str) -> dict:
        """工具执行逻辑"""
        result = f"Processed: {input_text}"
        return {"output": result}

# 扩展实例
extension = MyExtension()

事件钩子：

from openstarry_code.events import Event, EventHandler

class MyExtension(Extension):
    def on_load(self):
        # 注册事件处理器
        self.register_event_handler(
            "agent.before_execute",
            self.on_before_execute
        )
    
    def on_before_execute(self, event: Event):
        """Agent 执行前触发"""
        task = event.data.get("task")
        self.logger.info(f"Processing task: {task}")
        
        # 可以修改事件数据
        event.data["custom_context"] = {
            "timestamp": time.time()
        }

配置提供者：

from openstarry_code.config import ConfigProvider

class MyExtension(Extension):
    def get_config_schema(self):
        """定义扩展的配置模式"""
        return {
            "api_key": {
                "type": "string",
                "required": True,
                "description": "API key for external service"
            },
            "timeout": {
                "type": "integer",
                "default": 30,
                "description": "Request timeout in seconds"
            }
        }
    
    def on_config_changed(self, config: dict):
        """配置变更时调用"""
        self.api_key = config.get("api_key")
        self.timeout = config.get("timeout", 30)

Java 扩展开发

基础结构：

package com.example.myextension;

import io.openstarry.extension.Extension;
import io.openstarry.tools.Tool;
import io.openstarry.tools.ToolParameter;

public class MyExtension extends Extension {
    @Override
    public void onLoad() {
        registerTool(new MyCustomTool());
        getLogger().info("Java extension loaded");
    }
    
    @Override
    public void onUnload() {
        getLogger().info("Java extension unloaded");
    }
}

class MyCustomTool implements Tool {
    @Override
    public String getName() {
        return "my_custom_tool";
    }
    
    @Override
    public String getDescription() {
        return "Does something awesome";
    }
    
    @Override
    public Object execute(Map params) {
        String input = (String) params.get("input_text");
        String result = "Processed: " + input;
        
        Map output = new HashMap<>();
        output.put("output", result);
        return output;
    }
}

编译为 JAR：

# Maven
mvn clean package

# Gradle
gradle build

# 产出：target/my-extension-1.0.0.jar

Go 扩展开发

使用 CGO 构建共享库：

package main

import "C"
import (
    "encoding/json"
    "fmt"
)

type ToolRequest struct {
    Name   string            `json:"name"`
    Params map[string]interface{} `json:"params"`
}

type ToolResponse struct {
    Output interface{} `json:"output"`
    Error  string      `json:"error,omitempty"`
}

//export ExecuteTool
func ExecuteTool(requestJSON *C.char) *C.char {
    var req ToolRequest
    json.Unmarshal([]byte(C.GoString(requestJSON)), &req)
    
    // 工具逻辑
    result := fmt.Sprintf("Processed: %v", req.Params["input_text"])
    
    response := ToolResponse{
        Output: map[string]interface{}{
            "output": result,
        },
    }
    
    responseJSON, _ := json.Marshal(response)
    return C.CString(string(responseJSON))
}

func main() {}

编译为共享库：

# Linux
go build -buildmode=c-shared -o my-extension.so

# macOS
go build -buildmode=c-shared -o my-extension.dylib

# Windows
go build -buildmode=c-shared -o my-extension.dll

发布插件

发布到 GitHub

1. 仓库结构：

my-awesome-skill/
├── SKILL.md          # Skill 定义
├── README.md         # 项目说明
├── LICENSE           # 开源许可证
├── .gitignore
└── examples/         # 使用示例
    └── demo.md

2. 创建 Release：

# 打标签
git tag -a v1.0.0 -m "Release version 1.0.0"
git push origin v1.0.0

# 在 GitHub 上创建 Release

3. 用户可以通过 starry:// 协议安装：

starry://skill/install?github=yourname/my-awesome-skill
starry://skill/install?github=yourname/my-awesome-skill&ref=v1.0.0

发布到 ClawHub

ClawHub 是 OpenStarry Code 的官方插件市场。发布流程：

  1. 确保插件在 GitHub 上已公开
  2. 访问 clawhub.openstarry.dev
  3. 使用 GitHub 账号登录
  4. 点击"Submit Plugin"，填写表单：
    • GitHub 仓库 URL
    • 插件类型（Skill / Extension）
    • 分类标签
    • 简短描述
  5. 提交后等待审核（通常 1-3 个工作日）

审核通过后，用户可以通过以下方式安装：

starry://skill/install?clawhub=your-plugin-id

最佳实践

✅ 推荐做法

  • 提供清晰的 README 和使用示例
  • 使用语义化版本号（SemVer）
  • 在 SKILL.md 中详细说明用途和限制
  • 列出所有依赖项
  • 明确标注风险级别和所需权限
  • 保持向后兼容，谨慎破坏性变更

❌ 避免事项

  • 不要在插件中硬编码密钥
  • 不要执行未经用户确认的危险操作
  • 不要依赖未声明的外部服务
  • 不要使用模糊的 Skill 名称
  • 不要忽略错误处理
  • 不要在未告知的情况下收集用户数据
